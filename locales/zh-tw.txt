# ---- --help 文字 (help.<選項名稱>)
help.about = 看得見圖片的 `ls`。\n類似 `ls` 的檔案清單工具，在終端機中顯示圖片、影片與 PDF 的縮圖，使用 Sixel / Kitty / iTerm2 圖形、半塊字元或 ASCII 藝術。\n指定多個檔案、目錄或萬用字元，即可得到附有檔名的縮圖清單。
help.images = 圖片檔案、目錄或萬用字元（例如 ./*）。省略時為目前的目錄
help.regexp = 以正規表示式依檔名（不含目錄部分）篩選。重複指定時，符合其中任一個即可。例如：-e "\.png$" -e "(?i)^img_\d+"（(?i) 表示忽略大小寫）
help.recursive = 同時搜尋子目錄中的圖片（略過隱藏目錄）。在檔名前顯示上層目錄名稱
help.max_depth = 進入子目錄的深度（0：僅指定的目錄，1：再往下一層）。指定後不需要 -R 也會遞迴
help.sort = 排序依據。name 為遞增；date、size、exif-date 為最新優先、最大優先（-r 反向）
help.reverse = 反轉順序
help.head = 排序後只顯示前 N 張（例如 --sort date -n 20 表示最新的 20 張）
help.width = 輸出寬度（字元數）。單張圖片時為該圖片的寬度，清單時為整體寬度。不能與 --size 同時指定
help.size = 尺寸預設值（預設：s）。單張：24/40/80/120/160 欄；清單：每張縮圖 12/20/40/60/80 欄（xs/s/m/l/xl）
help.palette = text 模式的字元集預設值
help.custom_palette = 依由暗到亮的順序指定任意字元集（優先於 --palette）
help.invert = 反轉亮度
help.no_color = 關閉 ANSI 色彩（單色顯示）
help.no_links = 不為檔名加上超連結（Ctrl+點擊開啟）
help.no_pager = 輸出超出畫面時也不暫停（不使用 more 方式）
help.no_cache = 不使用繪製快取
help.cache_max_mb = 快取容量上限（MB，預設 256，或環境變數 GLS_CACHE_MAX_MB）。超出部分的舊項目會立即刪除
help.cache_days = 刪除這麼多天未使用的快取項目（預設 30，或環境變數 GLS_CACHE_DAYS）
help.cache_info = 顯示快取的位置、大小與上限，然後結束
help.clear_cache = 刪除全部繪製快取，然後結束
help.contrast = 對比度（1.0 為不變，越大越鮮明）
help.gamma = 伽瑪（1.0 為不變，大於 1 變亮，小於 1 變暗）
help.mode = 繪製模式。預設為 image（終端機的影像協定），無法使用時依終端機支援情況依序退回 half（TrueColor → 256 色）與 text（單色）。half 不能與 --no-color 同時使用（同時使用時為 text）。-p/--palette 僅在 text 時有效
help.protocol = --mode image 使用的影像協定。auto 依環境變數判斷
help.cell_size = 一個字元儲存格的像素大小（例如 10x20）。在 Sixel 下圖片與文字位置錯開時用來調整
help.grid = 清單的格線（每頁 COLSxROWS）。圖片較多時分頁輸出。省略時依終端機寬度盡量多排（列數為 2）。只指定 --width 時為 3x2
help.verbose = 在每個名稱下顯示圖片資訊。-v：像素尺寸與檔案大小；-vv：還顯示格式、色彩、像素數、長寬比、修改日期與 EXIF（相機與拍攝設定）
help.long = 類似 ls -l 的詳細清單。為每個檔案列出大小、尺寸、格式、日期、相機與拍攝設定（EXIF）等，在終端機中還會顯示縮圖。以管線輸出時，每個檔案一行的純文字。沒有內容可顯示的欄位會省略
help.thumbs_off = 與 -l 搭配時不顯示縮圖，只輸出每個檔案一行的表格（輸出以管線傳給其他指令時也是這種表格）
help.json = 以 JSON 輸出符合條件之檔案的資訊（每個檔案一個物件的陣列：路徑、大小、尺寸、格式、日期、EXIF）後結束。適合指令碼使用
help.null = 只輸出符合條件之檔案的路徑，以 NUL 字元分隔（用於 xargs -0），然後結束
help.lang = 訊息語言（例如 en、ja）。省略時依環境判斷

# ---- 錯誤與警告

err.glob = 萬用字元無效 `{arg}`：{err}
err.read_dir = 無法讀取目錄 `{arg}`：{err}

err.load_image = 載入圖片失敗：{err}
err.gamma_contrast = --gamma 必須大於 0，--contrast 必須大於或等於 0。
err.width = 寬度必須至少為 1。
err.palette = 字元集至少需要 2 個字元。
err.no_images = 找不到圖片檔案。
err.regex = 正規表示式無效：{err}
err.no_match = 沒有符合正規表示式的圖片。
warn.load = 無法載入 {path}：{err}
warn.no_protocol = 無法判斷終端機是否支援影像協定，改以字元顯示（可用 --protocol sixel|kitty|iterm2 指定）。
warn.unknown_lang = 語言 `{lang}` 無法使用（可用語言：{list}）。改用 {used}。
