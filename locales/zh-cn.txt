# ---- --help 文本 (help.<选项名>)
help.about = 图片版 `ls`：通过终端的图像协议（Sixel / Kitty / iTerm2）、半块字符或 ASCII 艺术在终端中显示图片。\n指定多张图片（支持通配符和目录），即可得到带文件名的缩略图列表。
help.images = 图片文件、目录或通配符（例如 ./*）。省略时为当前目录
help.regexp = 用正则表达式按文件名（不含目录部分）筛选。重复指定时，匹配其中任意一个即可。例如：-e "\.png$" -e "(?i)^img_\d+"（(?i) 表示忽略大小写）
help.recursive = 同时搜索子目录中的图片（跳过隐藏目录）。在文件名前显示上级目录名
help.max_depth = 进入子目录的深度（0：仅指定的目录，1：再往下一层）。指定后无需 -R 也会递归
help.sort = 排序依据。name 为升序；date、size、exif-date 为最新优先、最大优先（-r 反向）
help.reverse = 反转顺序
help.head = 排序后只显示前 N 张（例如 --sort date -n 20 表示最新的 20 张）
help.width = 输出宽度（列数）。单张图片时是该图片的宽度，列表时是整体宽度。不能与 --size 同时指定
help.size = 尺寸预设（默认：s）。单张：24/40/80/120/160 列；列表：每张缩略图 12/20/40/60/80 列（xs/s/m/l/xl）
help.palette = text 模式的字符集预设
help.custom_palette = 按从暗到亮的顺序指定任意字符集（优先于 --palette）
help.invert = 反转亮度
help.no_color = 关闭 ANSI 颜色（单色显示）
help.no_links = 不给文件名添加超链接（Ctrl+点击打开）
help.no_pager = 输出超出屏幕时也不暂停（不使用 more 方式）
help.no_cache = 不使用渲染缓存
help.cache_max_mb = 缓存容量上限（MB，默认 256，或环境变量 GLS_CACHE_MAX_MB）。超出部分的旧条目会立即删除
help.cache_days = 删除这么多天未使用的缓存条目（默认 30，或环境变量 GLS_CACHE_DAYS）
help.cache_info = 显示缓存的位置、大小和上限，然后退出
help.clear_cache = 删除全部渲染缓存，然后退出
help.contrast = 对比度（1.0 为不变，越大越鲜明）
help.gamma = 伽马（1.0 为不变，大于 1 变亮，小于 1 变暗）
help.mode = 渲染模式。默认是 image（终端的图像协议），不可用时按终端支持情况依次回退到 half（TrueColor → 256 色）和 text（单色）。half 不能与 --no-color 同时使用（同时使用时为 text）。-p/--palette 仅在 text 时有效
help.protocol = --mode image 使用的图像协议。auto 根据环境变量判断
help.cell_size = 一个字符单元的像素大小（例如 10x20）。在 Sixel 下图片与文字位置错位时用于调整
help.grid = 列表的网格（每页 COLSxROWS）。图片较多时分页输出。省略时按终端宽度尽量多排列（行数为 2）。只指定 --width 时为 3x2
help.verbose = 在每个名称下显示图片信息。-v：像素尺寸和文件大小；-vv：还显示格式、颜色、像素数、宽高比、修改日期和 EXIF（相机和拍摄参数）
help.long = 类似 ls -l 的详细列表。每个文件一行，列出大小、尺寸、格式、日期、相机和拍摄参数（EXIF）等。没有内容可显示的列会省略
help.thumbs = 与 -l 搭配，在每个文件的详细信息左侧显示图片缩略图（用 -s 调整大小）。隐含 -l
help.json = 以 JSON 输出匹配文件的信息（每个文件一个对象的数组：路径、大小、尺寸、格式、日期、EXIF）后退出。适合脚本使用
help.null = 只输出匹配文件的路径，以 NUL 字符分隔（用于 xargs -0），然后退出
help.lang = 消息语言（例如 en、ja）。省略时根据环境判断
