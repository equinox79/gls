# English (reference catalog). Format: key = message
# `\n` is a line break; {name} is a placeholder that must appear in every language.

# ---- --help text (help.<option name>)
help.about = `ls` for images: shows images in the terminal with an image protocol (Sixel / Kitty / iTerm2), half-block characters or ASCII art.\nGive several images (wildcards and directories work) to get a thumbnail list with file names.
help.images = Image files, directories or wildcards (e.g. ./*). Defaults to the current directory
help.regexp = Filter by file name (without the directory part) with a regular expression. Repeat to match any of several patterns. Example: -e "\.png$" -e "(?i)^img_\d+" ((?i) ignores case)
help.recursive = Also search subdirectories (hidden directories are skipped). The parent directory name is shown before the file name
help.max_depth = How deep to descend (0: only the given directory, 1: one level down). Implies -R
help.sort = Sort key. name is ascending; date, size and exif-date are newest / largest first (-r reverses)
help.reverse = Reverse the order
help.head = After sorting, show only the first N images (e.g. --sort date -n 20 for the newest 20)
help.width = Output width in columns: the image width for a single image, the whole output width for a list. Cannot be combined with --size
help.size = Size preset (default: s). Single image: 24/40/80/120/160 columns; list: each thumbnail 12/20/40/60/80 columns (xs/s/m/l/xl)
help.palette = Character set preset for text mode
help.custom_palette = Any character set, from dark to light (takes precedence over --palette)
help.invert = Invert brightness
help.no_color = Disable ANSI colors (monochrome)
help.no_links = Do not add hyperlinks (Ctrl+click to open) to file names
help.no_pager = Do not pause (like more) when the output does not fit the screen
help.no_cache = Do not use the render cache
help.cache_max_mb = Cache size limit in MB (default: 256, or the environment variable GLS_CACHE_MAX_MB). Old entries beyond it are removed right away
help.cache_days = Delete cache entries unused for this many days (default: 30, or the environment variable GLS_CACHE_DAYS)
help.cache_info =Show where the cache is, how big it is and its limits, then exit
help.clear_cache =Delete the whole render cache and exit
help.contrast = Contrast (1.0: unchanged; larger is punchier)
help.gamma = Gamma (1.0: unchanged; above 1 is brighter, below 1 is darker)
help.mode = Rendering mode. Default: image (terminal image protocol), falling back to half (TrueColor, then 256 colors) and then text (monochrome) depending on the terminal. half cannot be combined with --no-color (text is used then). -p/--palette applies to text only
help.protocol = Image protocol for --mode image. auto detects it from environment variables
help.cell_size = Pixel size of one character cell (e.g. 10x20). Adjust it when images and text are misaligned with Sixel
help.grid = Grid of a list (COLSxROWS per page); long lists are split into pages. By default as many columns as fit the terminal width (2 rows); 3x2 when only --width is given
help.verbose = Show image info under each name. -v: pixel size and file size; -vv: also format, color, megapixels, aspect ratio, modified date and EXIF (camera and shooting settings)
help.long = Long listing, like ls -l: one line per file with size, dimensions, format, dates, camera and shooting settings (EXIF) and more. Columns with nothing to show are left out
help.lang =Message language (e.g. en, ja). Default: detected from the environment
