# Русский. Машинный перевод; исправления приветствуются (см. README). Формат: key = сообщение
# `\n` — перевод строки; {name} — подстановка, которая должна быть такой же, как в en.txt.

# ---- текст --help (help.<имя параметра>)
help.about = `ls` с картинками.\nПросмотр файлов в стиле `ls`, который показывает миниатюры изображений, видео и PDF в терминале с помощью графики Sixel / Kitty / iTerm2, символов полублоков или ASCII-арта.\nУкажите несколько файлов, каталогов или шаблонов, и получится список миниатюр с именами файлов.
help.images = Файлы изображений, каталоги или шаблоны (например, ./*). По умолчанию — текущий каталог
help.regexp = Фильтр по имени файла (без пути к каталогу) с помощью регулярного выражения. Можно повторить, чтобы подошёл любой из нескольких шаблонов. Пример: -e "\.png$" -e "(?i)^img_\d+" ((?i) игнорирует регистр)
help.recursive = Искать и в подкаталогах (скрытые каталоги пропускаются). Перед именем файла показывается имя родительского каталога
help.max_depth = Глубина спуска (0 — только указанный каталог, 1 — на один уровень ниже). Подразумевает -R
help.sort = Ключ сортировки. name — по возрастанию; date, size и exif-date — сначала самые новые / самые большие (-r меняет порядок)
help.reverse = Обратный порядок
help.head = После сортировки показать только первые N изображений (например, --sort date -n 20 — 20 самых новых)
help.width = Ширина вывода в столбцах: ширина изображения для одного изображения, общая ширина для списка. Нельзя сочетать с --size
help.size = Готовый размер (по умолчанию: s). Одно изображение: 24/40/80/120/160 столбцов; список: каждая миниатюра 12/20/40/60/80 столбцов (xs/s/m/l/xl)
help.palette = Готовый набор символов для режима text
help.custom_palette = Любой набор символов, от тёмного к светлому (приоритетнее --palette)
help.invert = Инвертировать яркость
help.no_color = Отключить цвета ANSI (монохромный вывод)
help.no_links = Не добавлять к именам файлов гиперссылки (Ctrl+щелчок — открыть)
help.no_pager = Не останавливаться (как more), если вывод не помещается на экране
help.no_cache = Не использовать кэш отрисовки
help.cache_max_mb = Предел размера кэша в МБ (по умолчанию: 256 или переменная окружения GLS_CACHE_MAX_MB). Самые старые записи сверх предела удаляются сразу
help.cache_days = Удалять записи кэша, не использовавшиеся столько дней (по умолчанию: 30 или переменная окружения GLS_CACHE_DAYS)
help.cache_info = Показать, где находится кэш, его размер и пределы, и выйти
help.clear_cache = Удалить весь кэш отрисовки и выйти
help.contrast = Контрастность (1.0 — без изменений; больше — резче)
help.gamma = Гамма (1.0 — без изменений; больше 1 — светлее, меньше 1 — темнее)
help.mode = Режим отрисовки. По умолчанию: image (графический протокол терминала); в зависимости от терминала переключается на half (TrueColor, затем 256 цветов), а потом на text (монохромный). half нельзя сочетать с --no-color (тогда используется text). -p/--palette действует только для text
help.protocol = Графический протокол для --mode image. auto определяет его по переменным окружения
help.cell_size = Размер одной символьной ячейки в пикселях (например, 10x20). Измените, если при Sixel изображения и текст не совпадают по положению
help.grid = Сетка списка (COLSxROWS на страницу); длинные списки разбиваются на страницы. По умолчанию — столько столбцов, сколько помещается по ширине терминала (2 строки); 3x2, если указан только --width
help.verbose = Показывать сведения об изображении под каждым именем. -v: размер в пикселях и размер файла; -vv: также формат, цвет, мегапиксели, соотношение сторон, дата изменения и EXIF (камера и параметры съёмки)
help.long = Подробный список, как ls -l: для каждого файла размер, габариты, формат, даты, камера и параметры съёмки (EXIF) и другое, в терминале с миниатюрой. При передаче по конвейеру — простая строка на файл. Столбцы, в которых нечего показать, пропускаются
help.thumbs_off = С -l не показывать миниатюры, а выводить только таблицу «один файл — одна строка» (так же выводится, когда вывод передаётся по конвейеру)
help.json = Выводит подходящие файлы в формате JSON (массив с одним объектом на файл: путь, размер, габариты, формат, даты, EXIF) и завершает работу. Для скриптов
help.null = Выводит только пути подходящих файлов, разделённые символами NUL (для xargs -0), и завершает работу
help.lang = Язык сообщений (например, en, ja). По умолчанию определяется по окружению

err.load_image = Не удалось загрузить изображение: {err}
err.gamma_contrast = --gamma должно быть больше 0, а --contrast — не меньше 0.
err.width = Ширина должна быть не меньше 1.
err.palette = В палитре должно быть не меньше 2 символов.
err.no_images = Файлы изображений не найдены.
err.regex = Недопустимое регулярное выражение: {err}
err.no_match = Нет изображений, подходящих под регулярное выражение.
warn.load = Не удаётся загрузить {path}: {err}
warn.no_protocol = Терминал с графическим протоколом не обнаружен; вместо этого выводятся символы (выбрать протокол можно параметром --protocol sixel|kitty|iterm2).
warn.unknown_lang = Язык `{lang}` недоступен (доступные: {list}); используется {used}.
